# PixelCombat - beta cerrada

Action RPG 2D de pixel art: elige una de 4 clases (Guerrero, Pícaro, Mago o Arquero), sube la **Torre de las Cien Puertas**
con combate de acción a tiempo real, misiones, botín y oficios. Esta beta tiene **los 10 primeros pisos** (bosque del Cuervo).

## Descargar y jugar

1. Entra a **[Releases](../../releases)** y baja el archivo de la última versión:
   - **Windows:** `PixelCombat-<version>-windows.zip`. Descomprímelo y abre `PixelCombat.exe`.
   - **Linux:** `PixelCombat-<version>-linux.tar.gz`.
2. Windows puede avisar de "aplicación desconocida" porque el juego no está firmado: *Más información → Ejecutar de todos modos*.
3. Crea un personaje y entra a la torre desde la ciudad.

**Controles básicos:** WASD mover · clic derecho ataque básico (toque = golpe, mantener = golpe cargado) · clic izquierdo interactuar ·
Q/E/R skills · Espacio defensa/movilidad · F ultimate · I inventario · C ficha · Tab libro de skills · **F1 ayuda** · **Esc pausa**.

## Actualizar

En el menú principal pulsa **Buscar actualizaciones**. Si hay una versión nueva, el botón pasa a **Descargar vX** y abre la página del release:
baja el ZIP y sustituye el `.exe` viejo. **Tu partida no se pierde** (se guarda fuera del ejecutable).

## Qué me ayuda de tu prueba

- Pulsa **Copiar informe** (menú de pausa o menú principal) y pégalo en el chat con tus notas: lleva la versión, tu personaje, tiempos y muertes por piso.
- Dime qué piso se te hizo más difícil o injusto, si algo no se entiende, si ves tirones (F3 muestra los FPS) y si algún efecto se ve raro.
- Si algo falla: captura de pantalla + qué estabas haciendo + el informe.
